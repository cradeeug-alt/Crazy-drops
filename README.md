# Crazy-drops 🎧

Free DJ drops, right in your browser.

Crazy-drops is a web app for DJs to play and use drops (short audio tags and
shout-outs) during their sets. It's free to use.

## Features

- Play DJ drops instantly from the browser
- Simple, fast interface that works on phone and desktop
- Free, no sign-up needed

## Run it locally

1. Install [Node.js](https://nodejs.org)
2. Clone the repo:
   git clone https://github.com/cradeeug-alt/Crazy-drops.git
3. Go into the folder and install:
   cd Crazy-drops
   npm install
4. Start the server:
   node server.js
5. Open the address shown in the terminal (usually http://localhost:3000)

## Files

- `CRAZYDROPS.html` – the app interface
- `server.js` – the Node server
- `package.json` – project dependencies
